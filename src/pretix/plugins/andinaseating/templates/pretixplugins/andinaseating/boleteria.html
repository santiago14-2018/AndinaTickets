2. Cargar boletos impresos (los números los pone la imprenta)

{% bootstrap_form form layout="horizontal" %}
Ejemplo:
codigo;fila;butaca
0001234567;J;1
0001234568;J;2
El código tiene que ser exactamente lo que lee el escáner en el boleto (número o código de barras). Las butacas cargadas quedan reservadas para boletería. Los boletos de venta entran en la puerta recién cuando se venden (arriba, "Vender boletos de papel"); las cortesías, desde que se cargan. Si algo está mal, no se carga ningún boleto y te mostramos qué corregir.
Las ventas y las cortesías se cargan en archivos separados: un archivo para los boletos que se venden y otro para los de regalo.
